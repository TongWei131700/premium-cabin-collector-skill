## 快速上手

### 第一步：安装

```bash
npm install my-package
```

### 第二步：配置

创建配置文件 `config.js`：

```javascript
module.exports = {
  // 配置项
  key: 'value'
}
```

### 第三步：使用

```javascript
const myPackage = require('my-package')

myPackage.run()
```
